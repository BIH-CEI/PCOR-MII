CodeSystem: PCOR-MII Item Level Dictionary — Variablen-IDs (Experimentell)

Offizielle URL: https://bih-cei.github.io/PCOR-MII/CodeSystem/pcor-item-dictionary Version: 0.9.0
Draft Stand: 2026-09-30 Maschinenlesbarer Name: PcorItemDictionaryCS

Variablen-IDs des PCOR-MII Item Level Dictionary als Codes, damit sich ein flach erhobener Datensatz maschinell auf die Instrumenten-Questionnaires verteilen lässt (ADR-011). Jedes Item trägt seine Variable in item.code; die Zuordnung ist damit eine Nachschlage-Operation und keine Abbildung. Enthält nur die modellierten Variablen — content = fragment.

Dieses CodeSystem wird in der Definition der folgenden ValueSets referenziert:

  • This CodeSystem is not used here; it may be used elsewhere (e.g. specifications and/or implementations that use this content)

Eigenschaften

This code system defines the following properties for its concepts

NameCodeURITypeBeschreibung
instrument instrument https://bih-cei.github.io/PCOR-MII/CodeSystem/pcor-item-dictionary#instrument string INSTRUMENT-Spalte des Item Level Dictionary.
category category https://bih-cei.github.io/PCOR-MII/CodeSystem/pcor-item-dictionary#category string CATEGORY ID des Item Level Dictionary (GHS, DEM, MHI, MHA, DCH, TCH, EFA, MSE).
entity entity https://bih-cei.github.io/PCOR-MII/CodeSystem/pcor-item-dictionary#entity string Entität(en), in denen die Variable erhoben wird.
